# 端末別の回答・誤答記録

管理画面: https://rikkyo-uk-progress-api.fyam8.workers.dev/admin

Cloudflareの既存アカウントでログインし、端末の「回答・誤答を見る」から教科・年度とA/B日程・判定・問題IDで絞り込みます。端末にはNicknameを付けられます。同じブラウザの4教科は同じ端末として扱います。別ブラウザ・シークレットモード・サイトデータ削除後は別の端末登録になります。

送信内容は確定済みの回答・登録解答・採点方法・判定・解説・回答日時です。未確定の入力下書きは送信しません。長い文は「省略」と表示されます。通信できない場合は端末に残し再送します。過去の答案が残っていない履歴について、入力内容を推測して補いません。記述答案は自己採点・AI採点を区別し、非公式の登録解答を公式得点とみなしません。
